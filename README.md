# 项目初始化
> 快速创建sem项目，不需要任何配置

## 快速开始

1. 克隆仓库
    `git clone --recurse-submodules https://github.com/love-yuri/sem.git` 克隆仓库顺带初始化子仓库
2. 运行初始化脚本： `AppData/init.bat`
    1. 自动链接目录

    2. 自动拷贝文件到bin目录

    3. 自动切换分支到master


## 新增仓库

> 使用 `git submodule add -b master <url>` 添加子模块
>
> 再去.gitmodules里新增ignore就行。
